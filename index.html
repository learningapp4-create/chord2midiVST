Chord2MIDI

Iteration 1 · 21 November 2026 · VST3 phrase plugin

A musician picks a style and a chord line, then gets MIDI for a DAW track. This page is the project log. It opens in a browser with no build step.

Current capabilities

The plugin is a JUCE instrument that also sends MIDI. It holds one phrase: eight chords by default, one chord per bar in 4/4. Bass and treble are separate patterns on the same MIDI channel, so one instrument track can play both.

  • 24 styles from the ChordCanvas beat catalog, listed below.
  • Key of C, C#, D, Eb, E, F, F#, G, Ab, A, Bb, or B. Changing key transposes the current line. The status line names the key the style was catalogued in.
  • An editable chord line. Style chords reloads that style's line. New progression builds eight chords in the key: four diatonic degrees (I, ii, iii, IV, V, or vi, sometimes a major III or a minor iv), each with a colour tone, then the same four roots with a new colour.
  • Tempo from 40 to 200. Choosing a style sets tempo and feel to that style. The tempo slider is what Hear and the .mid file use. Host playback follows the DAW's timeline in bars, so the DAW tempo wins while the transport is running.
  • Feel: Straight (on the grid), Human, or Loose. Human and Loose lay some notes back. The drift is deterministic, so Hear and the file match.
  • Voicing: Shell (root and guide tones), Close (the chord in one register), or Full (a low root and fifth, plus the upper chord; wide styles also double the treble up an octave).
  • Rhythm: Style (that style's bass and treble grids, including its rest cycle), or an override: Block (quarter-note chords), Climb, Fall, or Pairs.

How MIDI reaches a track

  • Drag MIDI to a track. Drag that button out of the plugin onto a DAW track. JUCE writes a temporary .mid and starts a file drag. This is the reliable path when a host is picky about VST3 MIDI output.
  • Save MIDI… writes the same Standard MIDI file through a save dialog, if a drag is awkward on that desktop.
  • Host play. Put the plugin on an instrument or MIDI track and press play. It sends note-on and note-off for the phrase, one chord per bar, looping with the host timeline. Incoming MIDI is not passed through.
  • Hear. Starts an internal clock at the tempo slider, sends the same MIDI, and plays a plain preview tone so you can audition without a DAW.

The file is a type-1 Standard MIDI file, 960 ticks per quarter, one track, a tempo event, and a 4/4 time signature. Overlapping copies of the same pitch are shortened so a note-off lands before the next note-on.

Styles

Each style is the ChordCanvas beat of that name: its chord line, tempo, treble pattern, bass pattern, rest cycle, and timing feel. Grids are onsets per bar (a quarter note is one beat; a bar is four). A rest cycle such as 2-2-4 counts onsets and leaves a gap each time the count hits the next number. Patterns are block chords, a single rising or falling line, or adjacent pairs.

Symbols match the catalog, with two normalizations: Emsus2 is played and printed as Esus2, and Gsus as Gsus4. That shows up in Heartfelt and Relieve. Pitch names use one spelling (F#, Bb, Eb, Ab, C#), including after you transpose.

Settings in the plugin

ControlWhat it does
StyleLoads that style's chords, tempo, and feel. Voicing and rhythm stay where you left them.
KeyTransposes whatever line is showing.
ChordsComma-separated symbols, such as F#m7, Bbmaj9, C7sus4. A slash bass is ignored (C/E plays C). A trailing comma is left alone while you type.
Style chordsPuts the style line back without changing tempo or feel.
New progressionGenerates a new 8-chord line in the current key. The same seed always rebuilds the same line.
Tempo40–200 BPM for Hear and for the MIDI file.
FeelStraight, Human, or Loose.
VoicingShell, Close, or Full.
RhythmStyle, Block, Climb, Fall, or Pairs. Overrides keep the style's loudness shape.
Hear / StopInternal playback and preview tone.
Drag MIDI to a trackFile drag of the current phrase.
Save MIDI…Save dialog for the same file.

What this iteration added

  • An original phrase engine: chord symbols, the 24 style settings, voicing, rest cycles, contours, feel, and transposition.
  • A VST3 plus a standalone app, with a small editor for the controls above.
  • MIDI note output while the host plays, a Hear preview, and a .mid drag/save.
  • Command-line tests that check every style, transposition, rests, feel, and the MIDI file. They do not need JUCE.
  • This progress page.

Still missing

  • ChordCanvas can stack up to ten rows (intro, verse, chorus, and so on). This plugin is one row.
  • No separate sub-bass lane, no sustain-pedal CC, and no bass rest cycle of its own. Rests follow the treble cycle. The bass plays its grid.
  • Pattern modes here are block, climb, fall, and pairs. Later ChordCanvas modes (walk, guide, zigzag, bebop, approach, lick, resolve) are not in these 24 styles and are not implemented.
  • No multi-layer instruments, reverb, or WAV bounce. Hear is a plain tone, not the ChordCanvas piano.
  • Voicing is shell, close, or full. It is not a note-for-note copy of every ChordCanvas register.
  • Feel is a laid-back drift with its own timing, not a transcription of ChordCanvas's delay formula.
  • New progression is a diatonic 4+4 colour loop. It is not the full Imagine feature.
  • Incoming MIDI is ignored. The plugin does not yet trigger chords from a keyboard.
  • No AU or AAX. macOS and Windows binaries are not built here.
  • File drag depends on the desktop. If a host cannot accept a drag from a plugin window, use Save MIDI.

Build

Built on Linux x86-64 with gcc and g++ 13.3.0 (CMake 3.28, Release). phrase_tests passed. The VST3 is build/Chord2MIDI_artefacts/Release/VST3/Chord2MIDI.vst3, an ELF shared object at Contents/x86_64-linux/Chord2MIDI.so. The standalone app is build/Chord2MIDI_artefacts/Release/Standalone/Chord2MIDI. No DAW was available here, so the plugin was not loaded in a host. libcurl and webkit2gtk were not installed; this build turns the JUCE web browser and curl off.

Configure with cmake -S . -B build -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Release, then cmake --build build. Pin both compilers: the default c++ on the build machine was Clang and could not link libstdc++. CMake downloads JUCE 8.0.8. It is not stored in this repo. Phrase tests alone: -DCHORD2MIDI_BUILD_PLUGIN=OFF.

A Mac or Windows DAW still needs this project built on that platform (Xcode or Visual Studio), producing a .vst3 for that OS. The Linux bundle will not load there. Before shipping a binary, pick the JUCE licence you are actually using: AGPLv3 (and keep the JUCE splash screen) or a commercial JUCE licence. Details are in THIRD_PARTY_NOTICES.md. The Steinberg VST3 SDK arrives inside JUCE under its own terms.
